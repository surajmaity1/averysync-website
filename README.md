# Averysync

Experience real-time professional networking on Averysync through live spaces. Connect, collaborate, and make Averysync your daily stage for career growth.

## Getting Started

### Install Dependencies

```bash
pnpm install
```

### Start Development Server

```bash
pnpm dev
```

### Generate Routes

```bash
pnpm routes:generate
```

### To run workflow locally:

- [Act Docs](https://nektosact.com/usage/index.html)

```bash
act -W '.github/workflows/test.yml' --container-architecture=linux/amd64
```
